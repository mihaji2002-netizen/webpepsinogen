# پرونده محرمانه نهایی — Top Secret Final Dossier

اپلیکیشن رسمی **Pepsino Lab** برای تحلیل امتحانات نهاییِ پایه یازدهم.
یه تجربه‌ی «بازکردن پرونده‌ی محرمانه» — دارک، شیشه‌ای، سینمایی و کاملاً حرفه‌ای.

## ✨ ویژگی‌ها

- **فضای پرونده‌ی طبقه‌بندی‌شده (Classified):** تم تیره، گلَس‌مورفیسم، مُهرهای محرمانه، خط اسکن و افکت‌های نئونی نرم.
- **معماری کاملاً داده‌محور:** هیچ درس یا امتحانی در کد هاردکد نشده؛ همه‌چیز از `public/data` می‌آید.
- **بارگذاری تنبل (Lazy):** فقط مانیفستِ کوچک در صفحه‌ی اول بارگذاری می‌شود؛ سؤالات هر امتحان فقط هنگام ورود کاربر fetch می‌شوند.
- **جست‌وجوی آنی:** روی متن سؤال، تحلیل، فصل، پاسخ و کلیدواژه‌ها (با نرمال‌سازی فارسی).
- **فیلترها:** فصل، سطح سختی و نوع سؤال (به‌صورت داینامیک از خود داده ساخته می‌شوند).
- **پرونده‌ی کامل هر سؤال:** متن کامل و رسمی سؤال (بدون خلاصه‌سازی)، محل یادداشت دانش‌آموز، دکمه‌ی رمزگشایی جواب، پاسخ رسمی، تحلیل، نیّت طراح، اشتباه رایج، نکته‌ی شب امتحان و متادیتا (صفحه‌ی کتاب، بارم، فصل، سختی، احتمال تکرار).
- **موبایل‌فرست:** روی موبایل، تبلت و دسکتاپ عالی.

## 📁 ساختار داده‌ها

هر درس مستقل بارگذاری می‌شود. هیچ‌چیز داخل یک فایل بزرگ ذخیره نمی‌شود.

```
public/data/
  manifest.json          # فهرست درس‌ها، امتحان‌ها و شمارنده‌ها (درایورِ کل اپ)

    khordad1404.json
    shahrivar1404.json
    dey1404.json
  chemistry/ …
  persian/ …
  arabic/ …
  religion/ …

```

### افزودن محتوای جدید (بدون تغییر کد)

1. یک فایل JSON جدید در پوشه‌ی درس بساز (مثل `biology/khordad1405.json`).
2. آن را در `manifest.json` زیر امتحان‌های همان درس اضافه کن و `available: true` و مسیر `file` را بگذار.
3. تمام. درس و امتحان به‌صورت خودکار در UI ظاهر می‌شود.

برای افزودن یک **درس جدید**، فقط یک آیتم به آرایه‌ی `lessons` در `manifest.json` اضافه کن (آیکون، رنگ accent، تصویر و امتحان‌ها).
